# Главная страница Web Comp

Проект опубликован на Vercel. [Главная магазина](https://web-comp-store-demo.vercel.app/) · [Каталог дизайн-системы](https://web-comp-store-demo.vercel.app/catalog/)

Исходники и история хранятся в [открытом репозитории GitHub](https://github.com/Ozimnadius/web-comp-store-demo). После отправки коммита в ветку `main` Vercel запускает сборку Vite. Успешная сборка публикуется на основном адресе магазина.

Проект включает адаптивную главную интернет-магазина и каталог принятых компонентов дизайн-системы.

## Локальный запуск

Проверено с Node.js 24.21.0 и npm 11.19.0. При первом запуске выполните `npm ci` из корня проекта.

| Команда | Результат |
| --- | --- |
| `npm run dev` | [Главная магазина](http://127.0.0.1:5173/) и [каталог дизайн-системы](http://127.0.0.1:5173/catalog/) с обновлением при изменениях |
| `npm run build` | Готовые HTML, CSS и JavaScript в каталоге `dist/` |
| `npm run preview` | [Главная](http://127.0.0.1:4173/) и [каталог](http://127.0.0.1:4173/catalog/) из последней сборки |

В [указателе дизайн-системы](docs/design-system.md) собраны 312 ссылок на образцы, их узлы Figma и модули реализации. Прежние закладки с фрагментом в корне открывают тот же образец в каталоге. Для проверки запуска можно открыть [товарную карточку](http://127.0.0.1:5173/catalog/#product) или [малое контурное поле](http://127.0.0.1:5173/catalog/#inputs/152-48335).

Главная по умолчанию воспроизводит светлую синюю тему с максимальной шириной контента 1696 px. На экране шириной 1920 px доступны также варианты [1500 px в тёмной теме](http://127.0.0.1:5173/?container=1500) и [1296 px с красным акцентом](http://127.0.0.1:5173/?container=1296).

## Требования

- Семантическая разметка на HTML.
- Современный JavaScript. Поведение отдельных компонентов оформляем в самостоятельные модули с явными импортами.
- Стили на SCSS. Классы компонентов, их элементов и модификаторов именуем по БЭМ.
- Разработка и сборка через Vite.
- Для растровых изображений предпочтителен WebP.
- Документацию ведём на русском языке в Markdown. Исходники и документацию версионируем в Git.

## Состояние на 25 ноября 2026 года

Подготовлен [реестр макета](docs/inventory.md) с составом главной, размерами семи экранов и ссылками на источники изображений. В отдельных таблицах описаны [компоненты и состояния](docs/inventory-components.md) и [стили и переменные](docs/inventory-styles.md). На отдельном снимке видна палитра из 22 текстовых стилей. Её сверили со свойствами стилей Figma.

Пользователь принял реестр и четыре решения по вёрстке 25 ноября 2026 года. Решения по адаптивным коллекциям, первому баннеру, поведению элементов и оформлению кнопок записаны в конце реестра.

Пользователь принял дизайн-систему на HTML, SCSS и модульном JavaScript 25 ноября 2026 года. Команды запуска, сравнение с Figma и границы локальных взаимодействий приведены в [каталоге этапа 2](docs/design-system.md).

Главная собрана из компонентов библиотеки. Раскладки семи исходных фреймов, порядок секций и размеры карточек хранятся в [параметрах главной](src/home/layouts.json). На 768 и 375 px коллекции показаны один раз, после галереи. Товарные действия, выбор и прокрутка работают локально.

В опубликованной демоверсии ссылки ведут к разделам магазина и образцам дизайн-системы. Например, «Бренды» открывают ленту брендов, промобаннер ведёт к акциям, а «Документы» открывают образец сертификата. Видеоотзывы воспроизводят один [демонстрационный ролик MDN](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4). Форма подписки проверяет адрес в браузере. Для отправки адресов в рассылку требуется обработчик.

В [отчёте визуальной сверки](docs/visual-review.md) приведены парные снимки всех семи вариантов, результаты браузерных проверок и инструкция для повторения.

Порядок работ, результаты этапов и условия приёмки описаны в [плане проекта](docs/plan.md).
