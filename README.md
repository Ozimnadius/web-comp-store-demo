# Главная страница Web Comp

Проект включает дизайн-систему по семи ссылкам Figma и главную страницу, собранную из её компонентов. Дизайн-систему принимаем до начала вёрстки главной.

## Локальный запуск

Проверено с Node.js 24.21.0 и npm 11.19.0. При первом запуске выполните `npm ci` из корня проекта.

| Команда | Результат |
| --- | --- |
| `npm run dev` | [Демонстрация с обновлением при изменениях](http://127.0.0.1:5173/) |
| `npm run build` | Готовые HTML, CSS и JavaScript в каталоге `dist/` |
| `npm run preview` | [Локальный просмотр последней сборки](http://127.0.0.1:4173/) |

В [указателе дизайн-системы](docs/design-system.md) собраны 312 прямых ссылок на образцы, их узлы Figma и модули реализации. Для проверки запуска можно открыть [товарную карточку](http://127.0.0.1:5173/#product) или [малое контурное поле](http://127.0.0.1:5173/#inputs/152-48335).

## Требования

- Семантическая разметка на HTML.
- Современный JavaScript. Поведение отдельных компонентов оформляем в самостоятельные модули с явными импортами.
- Стили на SCSS. Классы компонентов, их элементов и модификаторов именуем по БЭМ.
- Разработка и сборка через Vite.
- Для растровых изображений предпочтителен WebP.
- Документацию ведём на русском языке в Markdown. Исходники и документацию версионируем в Git.

## Состояние на 25 ноября 2026 года

Подготовлен [реестр макета](docs/inventory.md) с составом главной, размерами семи экранов и ссылками на источники изображений. В отдельных таблицах описаны [компоненты и состояния](docs/inventory-components.md) и [стили и переменные](docs/inventory-styles.md). На отдельном снимке видна палитра из 22 текстовых стилей. Её сверили со свойствами стилей Figma.

Пользователь принял реестр и четыре решения по вёрстке 25 ноября 2026 года. Решения по адаптивным коллекциям, первому баннеру, поведению элементов и оформлению кнопок записаны в конце реестра.

Пользователь принял дизайн-систему на HTML, SCSS и модульном JavaScript 25 ноября 2026 года. Команды запуска, сравнение с Figma и границы локальных взаимодействий приведены в [каталоге этапа 2](docs/design-system.md).

Порядок работ, результаты этапов и условия приёмки описаны в [плане проекта](docs/plan.md).
